# קמפאיזי (CampEasy) - חנות ציוד קמפינג

חנות e-commerce ל-Next.js (App Router, TypeScript, Tailwind v4) עבור מוצרי קמפינג וטיולים, עם אינטגרציית CJdropshipping.

## הפעלה מקומית

**חשוב:** ההרצה חייבת להתבצע על המחשב שלכם (או שרת משלכם) - לא בתוך צ'אט/סביבת ענן של Claude, כי `localhost` תמיד מצביע על המכונה שמריצה את הפקודה, לא על מכונה אחרת.

1. שכפלו את הריפו ועברו לענף הרצוי (למשל):

   ```bash
   git clone https://github.com/guidny/e-commers.git
   cd e-commers
   git checkout claude/website-localhost-setup-j6gcr7
   ```

2. התקינו תלויות והריצו את שרת הפיתוח:

   ```bash
   npm install
   npm run dev
   ```

3. פתחו בדפדפן [http://localhost:3000](http://localhost:3000).

### פורט 3000 כבר תפוס?

אם יש לכם כבר פרויקט אחר שרץ על פורט 3000 (תראו את **האתר של הפרויקט האחר** בדפדפן, לא את קמפאיזי), הריצו על פורט אחר:

```bash
npm run dev -- -p 3001
```

ואז פתחו [http://localhost:3001](http://localhost:3001).

## מבנה הפרויקט

- `lib/products.ts` - קטלוג בסיס אוצר ביד (14 מוצרי קמפינג נבחרים, כולל המקלחת הניידת המבוקשת).
- `lib/pricing.ts` - לוגיקת תמחור: מרווח קבוע של **30%** מעל מחיר הספק (`MARKUP_RATE`), והמרה לשקלים (`USD_TO_ILS`).
- `lib/cj.ts` - קליינט שרת-בלבד ל-[CJdropshipping API v2](https://developers.cjdropshipping.com/) (אימות, חיפוש מוצרים, שליפת מוצר בודד).
- `lib/catalog.ts` - מאחד את הקטלוג הסטטי עם מחירים חיים מ-CJ (במידה ומוגדר `cjPid` למוצר וה-API זמין); נופל בחזרה למחיר המחקרי אם CJ לא זמין.
- `app/api/products` - נקודות קצה JSON לקטלוג.
- `app/api/cj/search` - נקודת בדיקה/ניהול לחיפוש מוצרים חיים ב-CJ (לאיתור `pid` לחיבור מוצר קיים למחיר חי).
- `app/api/checkout` - מקבל הזמנה מהצ'קאאוט, פותח הזמנה תואמת ב-CJ (ראו סעיף למטה) ושולח מייל אישור ללקוח.
- `lib/email.ts` - קליינט שרת-בלבד ל-[Resend](https://resend.com) לשליחת מייל אישור הזמנה.

## חיבור ל-CJdropshipping API

1. העתיקו `.env.example` ל-`.env.local`.
2. הדביקו את מפתח ה-API שקיבלתם מ-CJ (בעמוד "Get API Key" בפלטפורמת CJ) לתוך `CJ_API_KEY_RAW`, בפורמט `<userNum>@api@<secret>` בדיוק כפי שסופק. **חשוב:** CJ שולחת את המחרוזת הזו כמו שהיא בשדה `apiKey` בודד ל-`getAccessToken` (אומת ישירות מול ה-API החי) - לא כ-`email`/`password` מפוצל, בניגוד למה שגרסה קודמת של הקוד הניחה כשלא הייתה גישת רשת לבדוק.
3. **חשוב - אבטחה:** `.env.local` לא מחובר ל-git (`.gitignore` חוסם את כל קבצי `.env*`). אל תדביקו את המפתח בשום קובץ שנכנס ל-git, ואל תשתפו אותו בצ'אט/כלים ציבוריים. בפריסה (למשל Vercel) הגדירו את המשתנה כ-Environment Variable בהגדרות הפרויקט, לא בקוד.
4. **האינטגרציה נבדקה ואומתה בפועל** (לא רק לפי תיעוד) מול ה-API החי: אימות (`getAccessToken`), חיפוש קטלוג (`product/listV2`), פרטי מוצר/וריאנטים (`product/query`) וחישוב משלוח אמיתי לישראל (`logistic/freightCalculate`). 11 מתוך 14 המוצרים בקטלוג מחוברים כרגע ל-`cjPid`/`cjVid` אמיתיים עם עלות ומשלוח שנשלפו בפועל מ-CJ (`priceSource: "cj-live"`); 3 מוצרים (מנורת סולארית, פנס ראש, כיריים מיני) נשארו על הערכת מחקר (`priceSource: "estimated"`) כי לא נמצאה התאמה טובה בקטלוג של CJ בחיפוש - עדיף להשאיר הערכה כנה מאשר לחבר מוצר לא מתאים.
5. **מוצר אחד לא ניתן להזמנה כרגע**: "כלי רב-תכליתי להישרדות" (`multi-tool-survival-knife`) - CJ אימתה שאין אף אפשרות משלוח לישראל עבורו (כנראה מסווג כפריט חד/רגיש בדואר בינלאומי). הכפתור "הוסף לעגלה" מוסתר אוטומטית במקומו (`shipsToIsrael: false` ב-`lib/products.ts`) ומוצג הסבר במקום.
6. כדי לחבר מוצר נוסף למחיר חי מ-CJ, מצאו את ה-`pid`/`vid` שלו (דרך `/api/cj/search?q=...` או `product/listV2`) והוסיפו `cjPid`/`cjVid` לרשומה המתאימה ב-`lib/products.ts`.

## תמחור

- `MARKUP_RATE = 0.3` ב-`lib/pricing.ts` - מרווח של 30% מעל מחיר העלות, כמבוקש. שנו כאן אם תרצו מרווח אחר.
- `USD_TO_ILS` - שער המרה קבוע לתצוגה בשקלים; עדכנו לפי הצורך או חברו למקור שער חי.
- מחיר המשלוח לכל מוצר הוא ציטוט אמיתי של CJ ל-Israel (ערוץ "CJPacket Liquid Line"/"Sensitive", כ-9-27 ימים, נבחר כי הוא זול משמעותית מ-DHL וגם עקבי/מהיר יותר מהערוץ הזול ביותר "CJPacket Eub" שמגיע עד 50 יום) - לא מוכפל ב-30%, רק מחיר העלות מקבל את המרווח.
- מחירי מוצרים תחת `priceSource: "estimated"` הם הערכות מחקר (טווח מחירים אופייני ל-CJ למוצרים דומים), ולא מחירים חיים - יוחלפו אוטומטית ברגע שיוגדר `cjPid` מתאים.

## עגלת קניות, תשלום והזמנה אצל הספק

יש עגלת קניות מלאה (`/cart`) ותהליך "checkout" (`/checkout`) שאוסף פרטי משלוח - **ללא סליקת תשלום אמיתית מהלקוח מחוברת עדיין** (לחיבור סליקה כגון Tranzila / Cardcom / Stripe יש להוסיף אינטגרציה ייעודית בעתיד).

**מה כן קורה בפועל בלחיצה על "שליחת בקשת הזמנה"** (`app/api/checkout/route.ts`, `lib/cj.ts` - `createCjOrder`): עבור כל מוצר בעגלה שמחובר ל-`cjVid` אמיתי (ו-`shipsToIsrael` לא `false`), נפתחת **הזמנה אמיתית ב-CJdropshipping** דרך `POST /shopping/order/createOrderV2` עם `payType: 3` ("create only") - כלומר CJ **לא** מנסה לגבות תשלום באופן אוטומטי; ההזמנה נפתחת בדשבורד שלכם ב-CJ במצב ממתין, וצריך להיכנס לשם ולאשר/לשלם עליה ידנית לפני שהיא באמת נשלחת. זה מקביל ל"הזמנת טיוטה" - שום דבר לא קורה בפועל מול הלקוח עד שתאשרו. מוצרים שאין להם `cjVid` (כרגע: מנורת סולארית, פנס ראש, כיריים מיני - ראו סעיף החיבור ל-CJ למעלה) לא נשלחים ל-CJ אוטומטית ומופיעים ברשימת "מוצרים שדורשים הזמנה ידנית" במסך האישור ללקוח.
**נבדק בפועל** (2026-07-14): הרצה מלאה של הזרימה יצרה הזמנה אמיתית בדשבורד CJ (מספר `SD2607140010520667500`, נתוני בדיקה מסומנים בבירור) - כדאי להיכנס לדשבורד ה-CJ ולבטל/למחוק הזמנות בדיקה כאלה לפני שמתחילים לעבוד עם לקוחות אמיתיים.

## אימיילים ללקוחות (מייל אישור הזמנה)

כשלקוח שולח הזמנה, נשלח אליו מייל אישור עם פרטי ההזמנה (`lib/email.ts`, דרך [Resend](https://resend.com)) - **רק אם מוגדרים משתני הסביבה הרלוונטיים**; אם לא, ההזמנה עדיין מתבצעת כרגיל, פשוט בלי מייל (ותופיע הודעה על כך במסך האישור ללקוח, שקוף לצורכי דיבוג).

**כדי שהמיילים ייצאו מכתובת שלכם (ולא מכתובת גנרית/אנונימית)**, יש לבצע פעם אחת:

1. **פתחו חשבון חינמי ב-[resend.com](https://resend.com)** (החינמי מספיק ל-3,000 מיילים/חודש - מעל ומעבר לצרכים של חנות בהתחלה).
2. **דרוש דומיין משלכם** (למשל `campeasy.co.il`) - זו הדרך היחידה לשלוח מייל שנראה כאילו מגיע מכם ולא מ-`resend.dev`. אם אין לכם דומיין עדיין, אפשר לקנות אחד (לדוגמה ב-[Namecheap](https://namecheap.com) או מרשם דומיינים ישראלי) - עולה בדרך כלל כמה עשרות שקלים לשנה.
3. **הוסיפו את הדומיין ב-Resend** (Dashboard → Domains → Add Domain) - Resend ייתן לכם כמה רשומות DNS (SPF/DKIM) להוסיף אצל ספק הדומיין שלכם; אימות בדרך כלל לוקח כמה דקות עד שעה.
4. **צרו API Key** ב-Dashboard → API Keys, והדביקו אותו ל-`RESEND_API_KEY` ב-`.env.local` (ובהגדרות הסביבה ב-Vercel לפרודקשן).
5. **הגדירו `EMAIL_FROM`** לכתובת על הדומיין המאומת, למשל `"קמפאיזי" <orders@campeasy.co.il>`.
6. **הגדירו `STORE_OWNER_EMAIL`** לכתובת האימייל האמיתית שלכם - היא תשמש גם כ-reply-to (כשלקוח עונה למייל, זה מגיע ישירות אליכם, לא לכתובת אוטומטית) וגם תקבל bcc על כל הזמנה.

**חשוב לדעת**: אי אפשר "לשלוח מ-Gmail" באמת - ספקי מייל גדולים (Gmail/Outlook) לא מאפשרים לשירות חיצוני לשלוח בשמכם דרך ה-API שלהם מסיבות אבטחה (SPF/DKIM). הדרך הנכונה היא דומיין משלכם + Resend כמו שמתואר למעלה - זה מה שגורם למייל להיראות ולהתנהג כאילו הוא "ממך" (מהעסק שלך), כולל תגובות שחוזרות אליך ישירות.
